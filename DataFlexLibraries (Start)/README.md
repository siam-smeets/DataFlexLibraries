# DataFlex Libraries Training

This repository contains the **start** version of the DataFlex Libraries training workspace. The full folder name, `DataFlexLibraries (Start)`, is intended to be used at the beginning of the training.

## Overview

The workspace is a DataFlex 26.0 WebApp project for working with DataFlex libraries. It includes a sample web application using the DataFlex Web UI Server and Material Theme dependencies.

## Main Folders

- `AppSrc` - DataFlex application source files and web views.
- `AppHtml` - Web application HTML, CSS, images, and web configuration files.
- `Data` - DataFlex data files used by the sample application.
- `DDSrc` - Data dictionary and table definition source files.
- `Programs` - Workspace configuration and generated program output.

## Workspace

Open `DataFlexLibraries.sws` in the DataFlex Studio to begin the training from this starting point.
